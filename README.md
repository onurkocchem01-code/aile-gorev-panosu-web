# Aile Görev Panosu (web)

Anne, baba, çocuklar ve öğrenciler için ortak ev görevleri panosu.

**Uygulamayı açın:** https://onurkocchem01-code.github.io/aile-gorev-panosu-web/

- Aile kodu ile iPhone, Android ve bilgisayar aynı panoyu canlı görür (Firebase Firestore).
- iPhone: Safari → Paylaş → Ana Ekrana Ekle. Android: Chrome menüsü → Ana ekrana ekle.
- Android uygulaması (APK) ile aynı aile kodları kullanılır.

Bu depo yalnızca yayınlanan sayfa dosyalarını içerir. `fb-config.js` içindeki değerler herkese açık Firebase kimlik bilgileridir; erişimi Firestore güvenlik kuralları sınırlar.
